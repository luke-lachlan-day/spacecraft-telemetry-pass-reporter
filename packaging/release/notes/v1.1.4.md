# Spacecraft Telemetry Pass Reporter 1.1.4

## Windows download startup fix

- The portable bundle now includes an application-local .NET Framework configuration so its
  packaged pythonnet assemblies can load after a browser download and normal Windows Explorer
  extraction.
- The release workflow reproduces Windows Mark-of-the-Web metadata on a temporary copy of the
  finished bundle and requires both packaged diagnostic modes to pass before publication.
- The application does not remove security metadata or change machine-wide Windows policy.

## Download and verification

Download the versioned Windows x64 ZIP, matching `.sha256`, and build-information file from this
release. Verify the ZIP checksum, extract the complete folder with Windows Explorer, and run
`Telemetry Reporter.exe` beside its `_internal` folder. Python is not required.

The portable application is unsigned, so Windows SmartScreen may show an unrecognized-app warning.
It requires Microsoft Edge WebView2 Runtime, which current Windows 10 and Windows 11 installations
normally include.
