# Spacecraft Telemetry Pass Reporter 1.1.1

An AI-assisted learning and portfolio project with a local Windows desktop application and a typed
Python command-line interface. It validates fictional spacecraft-pass telemetry and generates a
self-contained HTML report through one shared Python analysis pipeline.

## Download and run

Download the versioned Windows x64 ZIP and its matching `.sha256` file from this release. Verify the
ZIP checksum, extract the complete folder, and run `Telemetry Reporter.exe` beside its `_internal`
folder. Python is not required.

The portable application is unsigned, so Windows SmartScreen may show an unrecognized-app warning.
It requires Microsoft Edge WebView2 Runtime, which current Windows 10 and Windows 11 installations
normally include.
