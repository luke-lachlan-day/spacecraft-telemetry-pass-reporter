# Spacecraft Telemetry Pass Reporter 1.1.3

## What the application does

This AI-assisted learning and portfolio project provides a local Windows desktop application and a
typed Python command-line interface. Both validate fictional spacecraft-pass telemetry and produce
polished, self-contained HTML reports through the same Python schema, analyser, and renderer.

## Desktop reliability

- Full-editor imports now build reading rows in one linear bulk operation, including at the
  documented 10,000-reading limit.
- Import, example, initialization, and save failures use dedicated operational feedback without
  erasing validation links or marking unchanged fields invalid.
- Save failures preserve the current analysis, preview, and save actions so the user can retry.
- Incidental Chromium diagnostics are redirected to private OS-temporary storage instead of the
  application or launch directory.

## Release safety

Version tags now run the complete Quality gate and Windows packaging workflow before a public
release is created. The packaged self-tests, real WebView2 smoke test, ZIP/checksum verification,
and workflow-artifact upload must all pass before GitHub receives the release notes and assets.
Manual workflow runs remain build-only.

## Download and verification

Download the versioned Windows x64 ZIP, matching `.sha256`, and build-information file from this
release. Verify the ZIP checksum, extract the complete folder, and run `Telemetry Reporter.exe`
beside its `_internal` folder. Python is not required.

The portable application is unsigned, so Windows SmartScreen may show an unrecognized-app warning.
It requires Microsoft Edge WebView2 Runtime, which current Windows 10 and Windows 11 installations
normally include.
